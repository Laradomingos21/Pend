Quais melhorias foram realizadas
    - Criação de um menu de navegação com o acesso a diferentes páginas do site.
    - Organização das notícias em cartões (cards) com imagem, título e descrição.
    - Página de clima com data, horário e informações em tempo real.
    - Reformulação das cores da interface, deixando mais moderna e profissional.
    - Notícias distribuídas com a sua própria categoria.
    - Aplicação de sombras, espaçamentos e alinhamentos.

Quais elementos semânticos foram utilizados
    - <header> o cabeçalho da página, contendo o título e o menu de navegação.
    - <nav>  agrupar os links do menu de navegação.
    - <main> o conteúdo principal de cada página.
    - <section> separar e organizar os grupos de notícias.
    - <article> representar cada notícia individualmente.
    - <footer>  o rodapé do site.

Quais Media Queries foram implementadas
    - Tablet (max-width: 768px) ajusta a largura dos cards para melhor aproveitamento do espaço.
    - Smartphone (max-width: 480px) adaptação do menu e ajuste do tamanho dos componentes para garantir que fique bom o site em telas menores.

Quais decisões de UX e UI foram adotadas
    - Utilização de um menu simples e intuitivo.
    - Uso de poucas cores e uma paleta consistente.
    - Fontes legíveis para facilitar a leitura das notícias.
    - Organização das informações em cartões.
    - Aplicação de espaçamentos adequados entre os elementos.
    - Desenvolvimento de um layout responsivo.
